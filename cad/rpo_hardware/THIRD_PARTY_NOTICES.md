# Third-party material

This repository includes reference models and design data for components that
may have been supplied by vendors, standards libraries or other third parties.
Inclusion in this repository does not mean that RoboParty owns those files or
has authority to relicense them.

Unless a file contains an explicit compatible licence notice, the repository's
`CERN-OHL-W-2.0`, `GPL-3.0-only` and `CC-BY-SA-4.0` grants do **not** apply to:

- vendor motor, battery, bearing, fastener, switch and electronic-module
  models;
- standard-parts library files, including files named after GB/T or other
  standards;
- supplier drawings, datasheets, CAD models, logos and product renders; or
- any other file whose copyright or design rights belong to a third party.

Examples currently visible in the repository include files named for DM
motors, OPI-5PLUS PCBA, LB22SA2M1-M10, SF1212, batteries, bearings and GB/T
fasteners. This list is illustrative, not exhaustive.

These assets are included only to describe interfaces, fit or assembly
context. Before reuse, verify the original source and licence with the
manufacturer or rights holder.

## Maintainer requirements

Before adding a third-party asset, record:

1. the file or directory path;
2. the supplier or rights holder;
3. the original source URL or delivery record;
4. the applicable licence or written redistribution permission; and
5. any attribution, distribution or manufacturing restrictions.

Where possible, replace embedded vendor models with a documented interface,
envelope model or link to the official supplier download.
